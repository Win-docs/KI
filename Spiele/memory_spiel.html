Kurze CSV-Anleitung anzeigen

Erstelle z. B. in Excel eine Tabelle mit zwei Spalten: links Begriff A, rechts Begriff B. Jede Zeile ist ein Paar. Speichere sie als CSV UTF-8 und wähle sie oben aus. Semikolon oder Komma als Trennzeichen funktioniert; eine Kopfzeile ist optional.
